# SearchForTheEgg

A Roblox game built with [Rojo](https://rojo.space/).

## Project structure

```
src/
├── client/   → StarterPlayer.StarterPlayerScripts.SearchForTheEgg
├── server/   → ServerScriptService.SearchForTheEgg
└── shared/   → ReplicatedStorage.SearchForTheEgg
```

## Setup

1. Install [Rokit](https://github.com/rojo-rbx/rokit) if you don't have it.
2. From the project root, run:

   ```
   rokit install
   ```

   This installs the pinned version of Rojo.

## Developing

1. Start the Rojo server:

   ```
   rojo serve
   ```

2. In Roblox Studio, open the **Rojo** plugin and click **Connect**.
